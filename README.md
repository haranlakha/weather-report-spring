# Weather Report Spring 

Weather Report program using [OpenWeatherAPI](https://openweathermap.org/api) data and [Spring Boot Framework](https://spring.io/projects/spring-boot).

## Setup

You will need to create an account with OpenWeatherAPI and get an API key. This is stored in the config.properties file.

## Installation

```
git clone https://github.com/haranlakha/weather-report-spring.git
```

## Compile code

Build the application in your favourite IDE e.g. [IntelliJ IDEA](https://www.jetbrains.com/idea/).
